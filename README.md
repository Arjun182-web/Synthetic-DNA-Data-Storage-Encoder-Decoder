# Synthetic DNA Data Storage Encoder and Decoder

## Overview

This project implements a Synthetic DNA Data Storage system using Flutter and Python Flask.

The application converts digital files into DNA nucleotide sequences (A, T, C, G) and reconstructs the original file from the generated DNA sequence.

## Features

- File Compression
- AES Encryption
- Binary to DNA Conversion
- FASTA File Generation
- DNA Decoding
- File Reconstruction

## Technology Stack

### Frontend
- Flutter
- Dart

### Backend
- Python
- Flask
